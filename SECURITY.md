# Política de Segurança / Security Policy — Economia_APP

**Versão:** `2026.11.22.0` | **Data:** `22 de novembro de 2026`  
**Version:** `2026.11.22.0` | **Date:** `November 22, 2026`

## 🇧🇷 Divulgação Responsável

Caso identifique uma vulnerabilidade de segurança, problema de validação de entrada, corrupção de memória ou falha de empacotamento nos binários do **Economia_APP**, **não abra uma issue pública**.

Envie um relato técnico detalhado para: **`fernando@nillsson.com.br`**

Inclua, sempre que possível:
- Versão afetada (`2026.11.22.0` ou posterior) e toolchain (`MSVC` ou `MinGW`);
- Passos para reprodução e impacto estimado.

Mais informações sobre controles nativos e hardening em [`docs/security-model.md`](docs/security-model.md).

---

## 🇺🇸 Security Vulnerability Reporting

Please do **not** file public issues for security vulnerabilities. Send responsible disclosure reports to **`fernando@nillsson.com.br`** with affected version, toolchain (`MSVC` or `MinGW`), and reproduction steps. See [`docs/security-model.md`](docs/security-model.md) for compiler and runtime hardening controls.
